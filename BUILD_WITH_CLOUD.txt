DEJA v0.7.0 — cloud build route (no Android SDK installation on your PC)

This ZIP is still Android source code, not an APK. The included GitHub Actions workflow can compile it on a GitHub-hosted Linux runner.

Steps:
1. Create or sign in to a GitHub account.
2. Create a NEW private repository, for example named DEJA-Android.
3. Extract this ZIP on your PC.
4. Upload the CONTENTS of the DEJA_Android_Project folder to the repository's main branch. Make sure the .github folder is included. On GitHub's upload page, hidden files may need to be included by using Git or GitHub Desktop.
5. Open the repository's Actions tab and select "Build DEJA Android APK".
6. Choose "Run workflow" if it did not start automatically after the upload.
7. When the run succeeds, open that workflow run and download the artifact named "DEJA-debug-apk".
8. Extract the artifact. It contains app-debug.apk. Transfer it to the Samsung phone and install it. Android may ask permission to install apps from that file manager; only allow it for the APK you built from this project.

Alternative: Open this project in Android Studio and use Build > Build Bundle(s) / APK(s) > Build APK(s).

IMPORTANT:
- The first build may fail if a source-code or dependency issue is found. Read the first red error in the Actions log; do not assume a failed build produced an APK.
- A successful debug build is not a Play Store release and is not proof every feature works. Test on the phone.
- This project is not an operating system. It is a normal Android app with supported Android integrations.
- Voice recognition and text-to-speech depend on Android services and installed language packs. Dedicated Oshiwambo offline voice engine remains excluded at the user's request.
- Calls, messages, biometric prompts, offline speech, and device-finder shortcuts are subject to Android/Samsung capabilities and permissions.
- Keep the GitHub repository private because it contains your app source. Do not upload passwords, API keys, or private identity codes.
