DEJA v0.8.9 — Build the APK in GitHub Actions

This ZIP contains Android Studio source code and a repaired cloud-build workflow. It is NOT itself an APK.

1. Extract this ZIP on your computer.
2. Upload the CONTENTS of the DEJA_Android_Project folder to the existing private DEJA GitHub repository's main branch. Include the hidden .github folder.
3. In GitHub, open the repository's Actions tab.
4. Select "Build DEJA Android APK" and choose "Run workflow" (or wait for the push-triggered run).
5. Open the completed workflow run. If it is green, download the artifact named "DEJA-debug-apk".
6. Extract the artifact; it contains app-debug.apk.

If the workflow fails, open the run and share the FIRST red error message or a screenshot of that section. Do not share passwords, API keys, or other secrets.

Important status notes:
- The previous failure was in Android SDK setup: the action tried to install the retired package "tools". This workflow now explicitly installs only platform-tools at that step, then installs platform 35 and build-tools 35.0.0.
- The project has no configured production DEJA gateway URL by default. The APK can compile with the URL blank, but online AI chat will not connect until a trusted adult configures the HTTPS gateway endpoint and the backend is deployed. Never place the OpenAI API key in the app, GitHub source, or APK.
- A debug APK is for testing, not a Play Store release. Install and test it on the intended Samsung phone before treating the build as complete.
- Calls and messages remain user-confirmed Android actions; this app does not silently answer calls or send messages in the background.
- Oshiwambo speech support still depends on a compatible recognition/speech provider and is not complete merely because the APK builds.
